Two QA fixture failures were investigated instead of treated as production bugs:

- Creative dimension transitions: the server acknowledgement file can precede client inventory packet handling. The old fixed eight-tick check observed an empty client slot immediately after a successful server assertion. The fixture now waits for the exact item/name/dimension state within its existing bounded timeout, and still fails persistent divergence. The 72-case rerun passed.
- Lore comparison: Polymer creates new styled wrapper components and prepends native container/dye tooltip lines. Component-tree equality or an assumed first position falsely rejected preserved lore. The fixture now matches rendered text with complete styles among generated lines and still verifies exact saved-source serialization roundtrips. This stricter visual test passed 1,767 checks on the initial candidate and led to the separate real compound-tooltip loss reproduction.

Initial sandbox server launches failed because localhost sockets were prohibited. Those attempts did not exercise gameplay and are excluded from pass counts. Subsequent disposable localhost server/client runs were authorized outside that sandbox. Expected client disconnect records during managed teardown are not treated as gameplay disconnections after suites have already passed.

The atlas changes received an independent source review after implementation. It checked complete template/count/order/selection preservation without capacity-limited insertion, current-input recipe assembly and ingredient immutability, client-only cache mutation and optional-mod gating. No blocking issue was found. The cache fixture was strengthened to track a non-atlas stale sentinel and an intentionally wrong cached center through real world transitions; requiring the entire cache to stay empty was incorrect because the active atlas can legitimately repopulate it while transition packets arrive.
